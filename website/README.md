# OpenReview website (Docusaurus v3)

Battle-tested OSS docs tool: Docusaurus (Meta, MIT, MDX, versioned docs, Algolia-ready).

```bash
cd website
npm install
npm start   # local preview
npm run build # static build -> deploy via GitHub Pages
```

Docs live in `website/docs/`. Config reference is generated from `../openreview.example.yml` + `../schema/openreview.schema.json` — keep them in sync.
